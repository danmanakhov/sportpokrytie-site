# Спорт-Покрытие: концепт-макет сайта

**Концепт-макет.** Это статическая одностраничная заготовка сайта ООО «Спорт-Покрытие» для обсуждения, а не опубликованный сайт компании. Форма заявки ничего не отправляет. Места с пометкой `[уточнить]` ждут подтверждённых данных (реквизиты, гарантия, допуски, объекты).

Фотографии и логотип взяты с действующего сайта https://sportpokrytie.ru/. Данные по услугам, контактам и примеру расчёта взяты с сайта и из коммерческих предложений компании.

Файлы: `index.html`, `assets/` (стили, логотип, фотографии).
